## About Project

Website manajemen inovasi berbasis Laravel untuk tugas akhir. Fitur utama:

- Dashboard admin
- Manajemen data inovasi
- CRUD operations
- Responsive design

## Tech Stack

- **Laravel 11**
- **MySQL**
- **Bootstrap/Tailwind**
- **jQuery**

## Installation

```bash
git clone https://github.com/PZIZZ505/WEBSITE_GETUKK01.git
cd WEBSITE_GETUKK01
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate
php artisan serve
```
